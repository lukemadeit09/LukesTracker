# Background art sources

All images are vintage engravings verified public domain (or CC0) at
download time via the Wikimedia Commons `extmetadata` API. Processed
locally (grayscale -> normalize -> optional invert -> contrast crush ->
2-color Floyd-Steinberg dither -> channel tint) with sharp; see repo
history for the scripts. Dark tints (blood red, dark green) are baked
into the PNG and rendered at higher opacity in ArtBackdrop.
